A FIRST-RUN ROUTE

Know what to do next.

A short guide, not a promise of a perfect run.

YOUR FIRST DECISION

Sword or wand?

Steel Sword

For close-range fighting. Expect to move near enemies.

Wooden Wand

For attacking from farther away. Keep space to move.

Starting weapons described by the game provider. Neither guarantees a winning run.

  1. Choose the fight you want.

    Compare the sword’s close-range attacks with the wand’s ranged attacks. Pick one to learn first: the choice changes how close you need to get to the crowd.

    Provider’s weapon description

  2. Move to collect experience.

    Drag the mouse to move. Defeated enemies leave loot that gives experience. Keep moving rather than waiting in one spot. The provider suggests a broad circular route to leave room around the crowd while collecting XP.

    Provider’s movement and XP advice

  3. Read the upgrade before choosing.

    As you collect experience, the game offers enhancements. Check whether a choice changes attack power, speed, or durability. Choose for the problem in that run rather than expecting one option to be best every time.

    Provider’s upgrade description

  4. Plan the next run after defeat.

    The provider describes menu upgrades to armor, healing, damage, and health using collected gold. Look at those choices before starting again. This website cannot inspect or restore the game’s saved progress.

    Provider’s between-run description

WHEN SOMETHING IS UNCLEAR

A few useful answers.

Do I use WASD or the mouse?

The provider documents dragging the mouse to move. Start with that control. Keyboard movement and touch controls have not been verified for this embed, so this page does not promise either.

Why does an ad appear before the game?

The embedded provider runs its own advertising flow. Follow its clearly labelled game controls and wait for any break to finish. Howbetter does not control those breaks.

If it stays stuck, try the provider’s game page. Reloading may interrupt the run; do not clear browser storage as a routine fix.

Will my upgrades be saved?

The provider says menu upgrades carry into later runs. Save persistence on this embed has not been independently verified here. The game manages its own browser data; Howbetter cannot back it up, transfer it between devices, or recover it.
